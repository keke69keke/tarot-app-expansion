# TarotUI

This module contains all SwiftUI views and `@Observable` ViewModels:

- `ContentView` — root `TabView` with five tabs.
- `TiradaView` / `TiradaDetailView` — spread animation and card detail.
- `BibliotecaView` — searchable card library grouped by arcana type and suit.
- `CartaDelDiaView` — daily card with flip animation.
- `DiarioView` / `DiarioEntryDetailView` — journal list and entry detail.
- `SettingsView` — user preferences.
- ViewModels: `TiradaViewModel`, `BibliotecaViewModel`, `DiarioViewModel`,
  `CartaDelDiaViewModel`, `SettingsViewModel`.

> Implemented in Tasks 9 and 10 of the implementation plan.
