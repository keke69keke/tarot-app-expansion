# TarotContent

This module bundles all static assets required by the app:

- `Resources/cards.json` — full catalogue of all 78 Rider-Waite cards with names,
  numbers, suits, arcana types, upright/reversed summaries (100–400 words),
  at least 3 keywords per orientation, and contextual interpretations per position.
- `Resources/` — card artwork images (PNG assets).

> `cards.json` is populated in Task 3.1 of the implementation plan.
> Card images are added separately as part of the art-asset delivery.
